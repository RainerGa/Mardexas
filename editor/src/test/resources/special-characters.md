# Überschrift – Sonderzeichen und Formatierungen

Ein Gedankenstrich – ein Geviertstrich — ein Auslassungspunkt … und 25 €.
Ein Pfeil ← und eine Linie ─ bleiben neben **Fett** und *Kursiv* erhalten.

> Ein Zitat — mit … und €.

- Erster Punkt – mit ←
- Zweiter Punkt ─ mit …

## Code und Links

`Preis: 25 € – Ende …`

[Link – mit Sonderzeichen](https://example.org)

```text
– — … € ← ─
```

| Zeichen | Beispiel |
|---|---|
| Gedankenstrich | – |
| Geviertstrich | — |
| Auslassung | … |
| Euro | € |
| Pfeil | ← |
| Linie | ─ |
