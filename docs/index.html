Mardexas (RichMarkDownEditor)

Desktop Markdown editor with a rich-text WYSIWYG interface for Linux, Windows, and macOS. Write Markdown visually without typing formatting markers by hand, and save UTF-8 CommonMark/GFM files. Built with JavaFX 25.

GitHub repository Releases API documentation License GPL-3.0

Platforms

  • Linux x86-64: Flatpak (io.github.rainerga.Mardexas), portable runtime archive, GraalVM native executable
  • Windows x86-64: MSI installer and portable ZIP
  • macOS: portable ZIP with Mardexas.app

Build from source

git clone --recurse-submodules https://github.com/RainerGa/Mardexas.git
cd Mardexas
mvn test
./editor/start.sh
