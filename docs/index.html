Why Mardexas?

Everything you need for productive writing

A desktop editor designed for content creators, authors, developers, and researchers who appreciate clean Markdown without the distraction of syntax characters.

✨

True WYSIWYG Editing

Style your text visually with familiar shortcuts and toolbar buttons. Headings, bold, italic, strikethrough, underline, and blockquotes render live directly while you write.

📊

Interactive Table Editor

Never struggle with pipe-and-dash ASCII syntax again. Mardexas features a first-class table editor with column alignment, cell navigation, and automatic GFM table formatting.

🔍

Find & Replace with Highlighting

Full-featured text and table search engine with case matching, whole-word search, occurrences highlighting, and instant replacement across your document.

⚡

Ultra-Fast Native Performance

Built with JavaFX 25 and GraalVM native images. Mardexas starts instantly, uses a fraction of the RAM of Electron-based apps, and keeps your laptop running cool.

🔒

100% Offline & Private

Your documents never leave your computer. There are no tracking scripts, mandatory accounts, telemetry, or proprietary cloud lock-ins. Pure local files.

🌐

Standard CommonMark & GFM

Mardexas reads and writes standard UTF-8 .md files compatible with GitHub, VS Code, Git version control, and static site generators.

📈

Document Statistics & History

Live word counts, character counts, reading time estimates, paragraph styles, forward/back navigation history, and optional line numbers in the gutter.

🌍

Available in 10 Languages

Native localized interface in German, English, French, Spanish, Brazilian Portuguese, Japanese, Simplified Chinese, Italian, Korean, and Dutch.

🧩

Embeddable JavaFX Library

Developers can embed Mardexas into their own Java/JavaFX desktop applications via a clean API (MarkdownEditor, file operations, swappable I18n).

📦 Embed Mardexas in your JavaFX Project

Use Mardexas as a rich markdown editor component inside your own Java/JavaFX application without dialogs:

<dependency>
  <groupId>de.richmarkdown</groupId>
  <artifactId>RichMarkDownEditor</artifactId>
  <version>1.0.0</version>
</dependency>
import de.richmarkdown.editor.MarkdownEditor;

MarkdownEditor editor = new MarkdownEditor();
rootPane.getChildren().add(editor.getControl());
editor.open(new File("README.md"));

FAQ

Frequently Asked Questions

Got questions about Mardexas? Find answers below.

What file formats does Mardexas support?

Mardexas natively opens and saves standard UTF-8 CommonMark and GitHub Flavored Markdown (.md, .markdown, .txt). Your documents remain 100% compatible with Git, VS Code, and any plain text editor.

Do I need to install Java to use Mardexas?

No! The release packages for Windows (.msi and .zip), Linux (Flatpak and portable tar.gz), and macOS (.app) bundle an optimized runtime image, so you can run Mardexas immediately without installing Java.

Is Mardexas really 100% free and open source?

Yes. Mardexas is licensed under the GNU General Public License v3.0 (GPL-3.0). There are no paywalls, no trial limits, and no hidden subscriptions.

How does Mardexas protect my privacy?

Mardexas operates entirely offline on your local computer. It does not send telemetry, analytics, or document contents to any external server.

Can I use Mardexas with Git or static site generators (Hugo, Jekyll)?

Yes! Because Mardexas saves standard CommonMark / GFM files without proprietary wrapper metadata, Git diffs remain clean, and files can be deployed directly with Hugo, Jekyll, Astro, or Docusaurus.

How can I contribute or report a bug?

Contributions, feedback, and bug reports are warmly welcome! Visit our GitHub repository to submit an issue, suggest features, or open a pull request.
